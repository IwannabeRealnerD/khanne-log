# 질문/결정 사항 템플릿

## 질문 섹션 형식

불명확한 경우 plan.md에 `## 질문` 섹션을 추가한다. 사용자는 각 질문 바로 아래 `> 답변:` 뒤에 답변을 작성한 후 `/blueprint`을 다시 호출한다. 체크박스는 에이전트가 처리한다.

```markdown
# 계획 제목

## 질문

아래 질문에 답변해주세요. 각 질문 바로 아래 `> 답변:` 뒤에 답변을 작성한 후 `/blueprint`을 다시 호출하세요.

- [ ] 질문 1?
  > 답변:
- [ ] 질문 2?
  > 답변:
```

## 결정 사항 변환 형식

답변이 채워지면 `## 질문` 섹션을 `## 결정 사항` 섹션으로 변환하여 맥락을 보존한다.

```markdown
## 결정 사항

- 인증 방식: JWT 사용 (세션 기반 대비 stateless 장점)
- 에러 처리: Toast로 통일 (Dialog는 사용하지 않음)
```
