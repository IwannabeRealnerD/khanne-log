## 검증 기준

### 1. 논리적 정합성
- Step 간 순서와 의존 관계가 올바른가?
- 이전 Step의 산출물이 다음 Step에서 필요한데 누락된 경우는 없는가?
- 영향 범위(생성/수정/삭제 파일)와 각 Step의 작업 내용이 일치하는가?
- 누락된 Step이 있는가? (예: API 훅을 만들지 않고 UI에서 사용하려는 경우)
- 하나의 Step에 너무 많은 작업이 몰려 있지는 않은가?

### 2. 사용자 의도 반영
- 개요의 작업 목표가 사용자의 원래 요청을 정확히 반영하는가?
- 결정 사항이 왜곡 없이 기록되었는가?
- 사용자가 명시한 범위를 벗어나거나, 요청하지 않은 작업이 포함되어 있지는 않은가?
- 추가 요청 사항이 각 Step에 적절히 반영되었는가?
