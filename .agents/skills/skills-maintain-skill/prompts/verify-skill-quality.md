# 스킬 품질 검증 프롬프트

## 역할

스킬 파일(SKILL.md)의 내용을 분석하여 품질 문제를 검출한다.

## 입력

검증 대상 스킬 파일의 전체 내용을 Read 도구로 읽는다.

## 검증 기준

### 1. 중복 내용

- 같은 규칙이나 지침이 다른 섹션에서 반복되는 경우
- 동일한 예시가 여러 곳에 등장하는 경우
- 표현만 다르고 의미가 같은 내용이 중복되는 경우

### 2. 논리적 모순

- 한 섹션의 규칙이 다른 섹션의 규칙과 충돌하는 경우
- 예시 코드가 본문의 규칙과 일치하지 않는 경우
- 조건문(~할 때, ~하면)의 조건이 상충하는 경우

### 3. 불필요한 장황함

- 한 문장으로 표현 가능한 내용이 여러 문장으로 늘어진 경우
- 자명한 내용을 별도로 설명하는 경우
- 불필요한 수식어나 반복 강조가 있는 경우

## 출력 형식

검증 결과를 아래 형식으로 반환한다.

```
## 검증 결과: [통과 | 수정 필요]

### 발견된 문제 (수정 필요인 경우만)

#### 문제 1: [중복 내용 | 논리적 모순 | 불필요한 장황함]
- **위치**: [섹션명 또는 줄 번호 범위]
- **내용**: [문제가 되는 구체적 내용 요약]
- **제안**: [수정 방향]

#### 문제 2: ...
```

## 판정 기준

- 발견된 문제가 0건이면 "통과"
- 1건 이상이면 "수정 필요"
- 사소한 표현 차이는 문제로 보지 않는다 (맥락이 다른 섹션에서 같은 용어를 사용하는 것은 중복이 아님)
